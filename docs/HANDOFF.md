## 2. 반드시 지켜야 할 약속 (선생님 요청 사항)

1. **문제는 교과서 범위로만** — 과학 4-2 「2. 생물과 환경」(과학 38~61쪽, 실험관찰 20~35쪽). 아래 6장의 교과서 요약을 기준으로 합니다.
   - AI Studio 버전에 있던 '생태계 평형', '녹말 합성·이산화탄소' 같은 범위 밖 내용은 **일부러 넣지 않았습니다.**
   - 교과서에 없는 생물(예: 고라니, 해마)도 등장하지만, 묻는 개념은 교과서 개념(생물/비생물, 생산자/소비자/분해자 등)만 씁니다.
2. **저작권 안내 문구 유지** — "비영리 교육용 팬 게임이며, 포켓몬 저작권은 Nintendo · Creatures · GAME FREAK · The Pokémon Company에 있고 제작자에게는 저작권이 없다."
   - 표시 위치: 첫 화면, 모든 화면 하단 띠(`#legal-strip`), ⓘ 버튼(`copyrightView()`), 인증서, README.
3. **포켓몬 이미지 파일을 저장소에 넣지 않기** — 화면에서 불러오기만 합니다. (AI Studio 버전에는 PNG 66개가 들어 있었지만 가져오지 않았음)
4. **지도·배경 그림은 직접 그린 SVG** (`js/art.js`) — 포켓몬 게임의 타일셋은 쓰지 않습니다.
5. **서버 없음, 개인 기록은 각 컴퓨터에만** — 학생 기록을 외부로 보내지 않습니다.
6. **랭킹은 선생님만** 봅니다. 학생 화면에는 랭킹을 보여 주지 않습니다.
7. **뽑기(확률형 아이템) 없음** — 상점은 모두 정해진 가격. (야생 등장 확률·희귀 포켓몬은 게임 진행 요소로만)
8. 결제·API 키·로그인이 없어 **비용이 나가지 않는다**는 점을 유지합니다.
9. 커밋 메시지·코드에 AI 모델 이름을 넣지 않습니다.

## 5. 기능 정리

### 지도 (11곳, `MAPS` / `MAP_ORDER`)
생태 마을(건물 9개) · 놀이 광장(게임 5개) · 학교 화단 · 숲길 · 흔적 공원(🐾 흔적 추리) · 푸른 산(생태통로) · 강가 · 황새 습지(논) · 공장 지대(☠️ 오염 정화) · 해변(쓰레기 줍기) · 국립공원 섬.
- 연결: 마을 ⬅️숲길(⬅️공원, ⬆️산) ➡️해변(➡️섬) ⬆️강가(⬅️습지, ➡️공장) ⬇️학교 화단(⬇️놀이 광장)
- 맵 문자: `T` 나무 `.` 풀 `=` 길 `,` 풀숲(만남) `L` 논(만남) `W` 물 `S` 모래 `F` 꽃 `R` 바위 `J` 쓰레기 `N`/`E` 안내판·생태통로 `O` 오염 `Q` 흔적 `h` 학교 건물 `f` 울타리 `p` 공장 `r` 도로 / 건물 글자는 `BUILDINGS` / `< > ^ v` 출구
- 맵을 고치면 모든 칸이 연결되는지 꼭 확인 (가로 15칸 × 세로 11줄).

### 포켓몬 · 진화
- 실제 생물 1종 ↔ 닮은 포켓몬 여러 마리(`WILD_POKEMON`). 앞쪽일수록 자주, 3번째부터 ✨희귀.
- 만나면 그 **실제 생물**에 대한 교과서 문제 → 맞히면 몬스터볼 연출, 포켓몬 도감 + 생태 도감 등록, 🍬사탕 3개.
- **사탕 진화**: 12개(1단계)/30개(2단계) — `evolveByCandy()`.
- **파트너 진화**: 스타터 18종은 Lv.7·Lv.15(이브이는 리피아/샤미드/부스터 선택), 잡은 포켓몬 파트너는 공식 진화 순서대로 3단계면 Lv.7·15, 2단계면 Lv.10 — `evoThresholds()`, `makeMonPartner()`(갈래 진화는 고르기).
- 10마리마다 보너스 코인, 30/80/150마리 칭호.

### 게임 13종
체육관 스토리(6스테이지) · 라운드전 · 스피드 퀴즈(60초) · 1:1 대결(한 기기, 마주 보기 모드) · 팀전(전자칠판, 2~4팀) · 기억력 카드 · 분류 두더지 · 먹이사슬 탑 · 생태 빙고 · OX 퀴즈쇼 · 오염 정화 디펜스 · (지도) 야생 만남 · 오염 정화/흔적 추리 칸

### 보상 · 꾸미기
코인(하루 한도 `dailyCoinLimit`), 경험치, 상점(사탕·새 파트너 입양 300·배경·칭호), 오늘의 미션(매일 3개, 이름+날짜로 정해짐), 날씨/밤에 따라 출현 생물 변화, 버디 쓰다듬기(친밀도).

### 학급 화폐 연동 (서버 없이 코드로)
- **코인 → 학급 화폐**: 환전소에서 환전 → **영수증 코드**(숫자 10자리, 학생 이름에 묶임) → 선생님 메뉴 「영수증 확인」에서 진위 확인 + "지급 완료" 표시(중복 방지는 선생님 기기에만 기록).
- **학급 화폐 → 게임 보상**: 선생님 메뉴 「쿠폰」에서 학생 이름용 1회용 **쿠폰 코드**(숫자 9자리: 코인/이상한 사탕/경험치 사탕).
- 코드 검증은 `codeSecret` + 이름으로 만든 짧은 해시(FNV). **한계**: 서버가 없어 코드 규칙이 공개 코드에 있음 → 마음먹고 분석하면 위조 가능. 초등 교실용으로는 충분하다고 안내함.

### 선생님 메뉴 (비밀번호 `CLASS_CONFIG.teacherPin`, 현재 `7314` — 바꾸라고 안내함)
🏅 랭킹(이 기기 학생 자동 + 학생이 보여 준 기록 코드 붙여 넣기, 선생님 기기에만 저장, 레벨/포켓몬/맞힌 문제/정답률/도감/별/라운드/스피드/대결/코인 정렬) · 🎟️ 쿠폰 · 🧾 영수증 확인 · 📚 수업(모든 스테이지 열기) · 👥 이 기기 학생(삭제).

### 저장 구조 (`localStorage['ecoPokemonExplorer.v2']`)

## 6. 교과서 범위 요약 (문제 출제 기준 — PDF는 저장소에 없음)

**과학 4-2 「2. 생물과 환경」 (과학 38~61쪽, 실험관찰 20~35쪽)**

- **38~41쪽 동물의 흔적** — 똥 박물관 이야기, 화단·공원에서 동물의 흔적(똥, 발자국, 깃털 등)을 찾아 사진을 찍고 상황을 추리. 안전: 쏘이거나 물리지 않게, 흔적을 맨손으로 만지지 않기, 긴 옷.
- **42~45쪽 생태계 구성 요소** — 생물 요소(살아 있는 것) / 비생물 요소(햇빛, 물, 공기, 흙). 한 지역에서 서로 영향을 주고받는 생물·비생물 요소를 통틀어 **생태계**. 크기는 쓰러진 나무 아래처럼 작을 수도, 섬처럼 클 수도.
  - 숲 그림: 상수리나무, 직박구리, 다람쥐, 흙, 뱀, 무당개구리, 버섯, 곰팡이(160배), 사슴벌레, 두더지, 지렁이
  - 강 그림: 햇빛, 공기, 매, 부들, 왜가리, 오리, 반달말(130배), 물, 붕어마름, 흙, 다슬기
  - 바다 그림: 햇빛, 갈매기, 공기, 돌고래, 물, 바다거북, 해파리, 톳, 산호, 고등어, 미역, 흙, 가오리, 게
- **46~47쪽 생물 요소의 역할** — **생산자**(식물, 햇빛 등으로 스스로 양분: 괭이밥·개망초), **소비자**(다른 생물을 먹이로: 박새·애벌레), **분해자**(버섯·곰팡이·일부 세균, 죽은 생물체나 배출물을 분해해 양분을 얻고 다른 생물이 이용하게). 생각: 분해자가 사라지면?
- **48~49쪽 먹이 관계** — 먹이 관계 모형 만들기 놀이(생산자 카드부터, 토끼풀 시작). 메뚜기는 풀, 개구리는 메뚜기 → **먹이사슬**. 오리는 메뚜기·개구리를 먹고 매·족제비에게 먹힘 → 여러 먹이사슬이 얽힌 **먹이그물**. 먹이그물이 복잡하면 어떤 생물이 사라져도 다른 먹이로 살 수 있어 **환경 변화의 영향을 적게 받고 생태계가 안정적**. 그림 속 생물: 도토리, 다람쥐, 뱀, 직박구리, 족제비, 산수유, 풀, 메뚜기, 토끼, 애벌레, 토끼풀, 오리, 개구리, 매. 실험관찰: 단순한 관계에서 개구리가 사라지면 매도 살 수 없음, 복잡한 관계에서는 직박구리·오리·족제비를 먹고 살 수 있음.
- **50~51쪽 인간 활동과 환경오염** — 환경오염(환경이 더러워지거나 훼손되는 현상): **대기·수질·토양오염**. 원인: 자동차·공장 매연, 생활 하수·공장 폐수, 기름 유출, 농약의 지나친 사용, 쓰레기, 플라스틱 과도한 사용. 영향: 서식지(생물이 일정하게 자리 잡고 사는 곳) 파괴, 생물 종류와 수 감소. 플라스틱: 태우면 해로운 물질(대기)·**미세 플라스틱(5 mm 이하)** 이 물속 생물 피해(수질)·썩는 데 오래 걸려 서식지 파괴(토양). 조사 자료는 출처를 밝히기.
- **52~53쪽 생태계 보전** — 카드 뉴스: 우리나라 연안 죽은 **바다거북 10마리 중 8마리**가 플라스틱을 먹음. 노력: **생태통로**, 물고기가 이동할 수 있는 통로, 투명 방음벽 **새 충돌 방지 스티커**, **생태계 보호 구역**(한려 해상 국립 공원), 일회용품 줄이기, 에너지 절약. 마스크 함부로 버리면?
- **54~55쪽 실천** — 사람도 생태계의 일부. 활동 계획(활동 내용·기간), 건의하는 글, 캠페인, 모둠 협약, 실천 점검표.
- **56~57쪽 우리 주변 생물 조사** — 생물을 기록하는 애플리케이션·누리집('생물 탐사', '생물다양성'), 박새(머리·목 검은색, 뺨 흰색, 곤충·씨앗·열매), 달맞이꽃, 국립생물자원관, 출처 밝히기.
- **58~59쪽 황새** — 전 세계 3,000여 마리의 국제적 멸종 위기종·천연기념물, 밀렵·농약·서식지 파괴로 1970년대 초 자취 감춤, **1996년부터 복원 연구**, 2020년생 '엔젤'(다리 고리 B11)이 **24시간 1,200 km** 날아 **대만** 도착, **위치 추적기**로 이동 경로 파악(반달가슴곰·돌고래·바다거북도). 텃새·밀렵 뜻.
- **60~61쪽 정리** — 초성 퀴즈(ㅅㅁ/ㅂㅅㅁ 요소, ㅅㅂㅈ, ㅁㅇㄱㅁ, ㅌㅇ 오염, ㅅㅌㄱ), 먹이그물 붙임딱지(매, 뱀, 족제비, 토끼, 다람쥐, 도토리, 토끼풀).

## 7. 자주 하는 수정 방법

| 하고 싶은 것 | 고칠 곳 |
|---|---|
| 비밀번호·학급 화폐·한도 | `js/config.js` (GitHub 웹에서 연필 버튼으로 수정 가능) |
| 문제 추가 | `js/questions.js` 의 `QM(주제, 질문, 정답, [오답…], 해설, 그림)` / `QX(주제, 문장, 참거짓, 해설, 그림)` |
| 생물 추가 | `js/data.js` `CREATURES` + `js/pokemon.js` `WILD_POKEMON`(이름은 PokeAPI CSV로 확인) + 지도 `pool` |
| 지도 추가/수정 | `js/data.js` `MAPS` (15×11), 연결은 `exits`, 순서는 `MAP_ORDER` |
| 새 게임 | `js/minigames.js` 패턴(`simpleIntro` → `run…` → `resultScreen`) + `BUILDINGS` 글자 + `town.js` `openPlace()` |
| 그림 | `js/art.js` (`ground`, `object`) |

주의: `h()` 로 만든 요소의 `style` 에 CSS 변수(`--x`)를 넣으면 `setProperty`로 처리됨. `element.append(null)` 은 "null" 글자를 출력하니 쓰지 말 것.
