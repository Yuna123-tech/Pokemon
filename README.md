# 포켓몬 생태계 탐험대 🌳⚡

초등학교 4학년 2학기 과학 **「2. 생물과 환경」** 단원을 포켓몬과 함께 배우는 웹 게임입니다.
설치 없이 브라우저(크롬북·태블릿·PC)에서 바로 실행됩니다.

> ⚠️ **저작권 안내**
> 이 게임은 초등학교 수업을 위해 만든 **비영리 팬 게임(Fan Game)** 입니다.
> 포켓몬스터(Pokémon)의 이름, 캐릭터, 이미지에 대한 모든 저작권과 상표권은
> **Nintendo, Creatures Inc., GAME FREAK inc., The Pokémon Company**(한국: 포켓몬코리아)에 있으며,
> **제작자에게는 포켓몬 관련 저작권이 없고**, 공식 회사와 아무런 관련이 없습니다.
> 상업적 목적으로 사용하지 않으며, 게임 속 코인은 실제 돈과 관계없습니다.
> 포켓몬 이미지는 저장소에 포함하지 않고 공개 저장소 [PokeAPI/sprites](https://github.com/PokeAPI/sprites)에서 실행할 때 불러옵니다.
> 저작권자의 요청이 있으면 즉시 게시를 중단합니다.

## 💰 비용 · 보안 · 개인정보
- 결제 기능, API 키, 로그인, 서버, 데이터베이스가 **없습니다.** 돈이 나갈 일이 없습니다.
- GitHub Pages는 공개 저장소에서 무료입니다.
- **모든 게임 기록은 게임을 하는 그 컴퓨터의 브라우저(localStorage)에만 저장**되고 밖으로 전송되지 않습니다.
  (인터넷 사용 기록 삭제나 시크릿 창에서는 기록이 지워질 수 있어요.)
- **랭킹은 선생님만** 볼 수 있습니다. 학생 화면에는 랭킹이 없습니다. (아래 「랭킹」 참고)

## 실행 방법
- `index.html`을 크롬이나 엣지로 엽니다. 또는 GitHub Pages(Settings → Pages)로 주소를 만들어 학생들에게 나눠 줍니다.
- 포켓몬 이미지를 불러오려면 인터넷 연결이 필요합니다. (이미지가 막히면 이모지로 대신 보여 줍니다.)

## 🛠️ 선생님 설정 — `js/config.js`
GitHub에서 `js/config.js` → ✏️ 연필 버튼 → 값 수정 → **Commit changes** 하면 모든 기기에 적용됩니다.

| 설정 | 기본값 | 설명 |
|---|---|---|
| `teacherPin` | `7314` | 선생님 메뉴 비밀번호 — **꼭 바꿔 주세요** |
| `currencyName` / `currencyUnit` | 학급 화폐 / 원 | 우리 반 화폐 이름과 단위 |
| `coinsPerUnit` | 100 | 게임 코인 몇 개 = 학급 화폐 1 |
| `dailyExchangeLimit` | 3 | 하루 환전 최대 수량 (0이면 환전 끔) |
| `dailyCoinLimit` | 300 | 하루에 벌 수 있는 최대 코인 (게임 과몰입 방지) |
| `codeSecret` | eco-pokemon-4-2 | 쿠폰·영수증·기록 코드용 비밀 단어 |

> 참고: 서버가 없는 게임이라 비밀번호와 비밀 단어는 공개 저장소의 코드에서 볼 수 있습니다. 초등 교실용으로는 충분하지만, 완벽한 보안 장치는 아닙니다.

## 🎮 게임 구성

### 생태 마을 (걸어 다니는 맵)
화면을 누르거나 방향키로 걸어 다녀요. **생태 마을 · 숲길 · 강가 · 해변** 4개 지역이 있고,
**풀숲(🌾)** 에서 야생 생물을 만나면 그 생물에 대한 교과서 문제가 나옵니다. 맞히면 도감에 등록!
해변에서는 쓰레기(🥤)를 주워 바다를 지킬 수 있어요.

### 건물 = 게임 종류
| 건물 | 게임 | 특징 |
|---|---|---|
| 🏟️ 체육관 길 | **스토리** | 교과서 순서대로 6개 스테이지 (생물·비생물 요소 → 생산자·소비자·분해자 → 먹이사슬·먹이그물 실험실 → 환경오염 → 생태계 보전 → 챔피언) · 인증서 인쇄 |
| 🏆 라운드 아레나 | **라운드전** | 라운드마다 도전자를 이기는 서바이벌, ❤️ 3개, 갈수록 짧아지는 제한 시간 |
| ⏱️ 스피드 트랙 | **스피드 퀴즈** | 60초 동안 콤보로 최대 점수, 끝나면 틀린 문제 해설 복습 |
| ⚔️ 대결장 | **1:1 대결** | 한 기기에서 둘이 먼저 맞히기 대결, 급소 공격, 마주 보기 모드(화면 뒤집기) |
| 👥 팀전 경기장 | **팀전** | 전자칠판용 모둠 대항전(2~4팀), 선생님이 정답 공개 후 맞힌 팀에 점수, 보너스 라운드, 팀 포켓몬 진화 |
| 🃏 기억력 카드 | **짝 맞추기** | 교과서 낱말 ↔ 뜻 카드 뒤집기 |
| 🏥 포켓몬센터 | 내 파트너 | 레벨·진화, 가방(사탕), 파트너 바꾸기, 칭호·배경, 기록 코드 |
| 🏪 상점 | 보상 | 경험치 사탕, 이상한 사탕, 새 파트너 입양, 배경, 칭호 |
| 💱 환전소 | 학급 화폐 | 코인 → 학급 화폐 영수증, 선생님 쿠폰 쓰기 |

모든 게임에서 **문제 범위(소주제 1~5)** 를 골라 차시에 맞게 쓸 수 있습니다.

### 파트너 포켓몬 · 레벨업
- 처음에 8마리 중 파트너를 골라요 (이상해씨, 파이리, 꼬부기, 피츄, 모부기, 치코리타, 캐터피, 이브이).
- 문제를 맞히면 경험치와 코인을 받아요. **Lv.7, Lv.15에 진화**하고, 이브이는 진화할 모습을 직접 골라요.
- 뽑기(확률형 아이템)는 넣지 않았습니다. 모든 보상은 정해진 가격으로 삽니다.

### 📚 문제은행 (교과서 범위로만 출제)
과학 38~61쪽 · 실험관찰 20~35쪽 내용으로 만든 **162문제** (객관식 + OX)
1. 생태계 구성 요소 · 2. 생산자·소비자·분해자 · 3. 먹이사슬·먹이그물 · 4. 환경오염 · 5. 생태계 보전(황새 위치 추적기 포함)

## 💱 학급 화폐 연동
서버 없이 **코드**로 연결합니다. 코드는 학생 이름과 묶여 있어 다른 학생이 쓸 수 없습니다.
- **게임 코인 → 학급 화폐**: 학생이 💱 환전소에서 환전하면 **영수증 코드**가 나와요.
  선생님 메뉴 → 🧾 영수증 확인에 이름과 코드를 넣으면 진짜인지 확인되고, "지급 완료"를 눌러 두면 같은 영수증을 두 번 받을 수 없어요.
- **학급 화폐 → 게임 보상**: 선생님 메뉴 → 🎟️ 쿠폰에서 학생 이름으로 **1회용 쿠폰**(코인/사탕)을 만들어 주면, 학생이 환전소에서 입력해요.

## 🏅 랭킹 (선생님만)
- 선생님 메뉴 → 🏅 랭킹: **이 컴퓨터에 있는 학생**은 자동으로 나와요.
- 다른 컴퓨터의 학생은 포켓몬센터 → 트레이너 카드 → **기록 코드**를 보여 주면, 선생님이 이름과 코드를 붙여 넣어요. **선생님 컴퓨터에만** 저장됩니다.
- 레벨, 맞힌 문제, 정답률, 도감, 별, 라운드전, 스피드, 대결 승리, 모은 코인 순으로 정렬할 수 있어요.

js/modes.js       라운드전, 스피드, 대결, 팀전, 기억력 카드
