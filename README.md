# 포켓몬 생태계 탐험대 🌳⚡

초등학교 4학년 2학기 과학 **「2. 생물과 환경」** 단원을 포켓몬과 함께 배우는 웹 게임입니다.
설치 없이 브라우저(크롬북·태블릿·PC)에서 바로 실행됩니다.

> ⚠️ **저작권 안내**
> 이 게임은 초등학교 수업을 위해 만든 **비영리 팬 게임(Fan Game)** 입니다.
> 포켓몬스터(Pokémon)의 이름, 캐릭터, 이미지에 대한 모든 저작권과 상표권은
> **Nintendo, Creatures Inc., GAME FREAK inc., The Pokémon Company**(한국: 포켓몬코리아)에 있으며,
> **제작자에게는 포켓몬 관련 저작권이 없고**, 공식 회사와 아무런 관련이 없습니다.
> 상업적 목적으로 사용하지 않으며, 포켓몬 이미지는 저장소에 포함하지 않고
> 공개 저장소 [PokeAPI/sprites](https://github.com/PokeAPI/sprites)에서 실행할 때 불러옵니다.
> 저작권자의 요청이 있으면 즉시 게시를 중단합니다.
> (게임 첫 화면, 모든 화면 아래쪽 띠, ⓘ 버튼, 인증서에 같은 안내가 들어 있습니다.)

## 실행 방법

- **가장 쉬운 방법**: `index.html` 파일을 더블클릭해 크롬이나 엣지로 엽니다.
- **학생들에게 링크로 나눠 주기 (GitHub Pages)**
  1. 저장소 → **Settings → Pages**
  2. Source: `Deploy from a branch`, Branch: 이 브랜치(또는 `main`) / `(root)` 선택 → Save
  3. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소로 접속합니다.
- 포켓몬 이미지는 인터넷에서 불러오므로 **인터넷 연결이 필요**합니다.
  (`raw.githubusercontent.com`이 막힌 학교망에서는 `cdn.jsdelivr.net`으로 한 번 더 시도하고,
  그래도 안 되면 이모지로 대신 보여 줍니다.)

| 스테이지 | 학습 내용 | 교과서 | 활동 |
|---|---|---|---|

| 2. 역할 연구소 🍄 | 생산자 · 소비자 · 분해자 | 과학 46~47쪽, 실험관찰 22~23쪽 | 생물 카드 역할 분류, "분해자가 사라지면?" |
| 3. 먹이그물 언덕 🕸️ | 먹이사슬과 먹이그물 | 과학 48~49쪽, 실험관찰 24~25쪽 | 먹이사슬 카드 순서 맞추기, **먹이그물 실험실**(생물을 없애 보며 변화 관찰), 단순 vs 복잡한 먹이 관계 |
| 4. 오염 몬스터 공장 🌫️ | 인간 활동과 대기·수질·토양오염 | 과학 50~51쪽, 실험관찰 26쪽 | 오염 원인을 3가지 오염으로 분류, 미세 플라스틱 |
| 5. 바다 지킴이 해변 🐢 | 생태계 보전을 위한 노력 | 과학 52~55쪽, 실험관찰 27~29쪽 | 바다거북 구하기 쓰레기 줍기 미니게임, 도움/해가 되는 행동, 생태통로·물고기 통로·새 충돌 방지 스티커·보호 구역, 실천 다짐 |
| FINAL 챔피언 리그 🏆 | 단원 정리 | 과학 56~61쪽 | 초성 퀴즈 등 정리 문제 11개, 황새 위치 추적기 이야기 → **생태 마스터 인증서**(인쇄 가능) |

### 게임 특징
- **배틀 형식 퀴즈**: 정답을 맞히면 관장의 HP가 줄고 생물이 **생태 도감**에 등록됩니다.
- **틀려도 괜찮아요**: 틀리면 해설이 나오고, 그 문제는 뒤에 다시 나옵니다. 틀린 횟수에 따라 별(★)을 받습니다.
- **포켓몬 = 실제 생물의 모델**: 예) 상수리나무 → 도토링, 다람쥐 → 파치리스, 버섯 → 깜놀버슬, 바다거북 → 꼬부기.
  카드에는 **실제 생물 이름**이 크게, 닮은 포켓몬 이름은 작게 표시됩니다.
- **생태 도감 32종**: 스테이지 1은 할 때마다 다른 생물이 나와서 다시 하며 도감을 채울 수 있습니다.
- **선생님 메뉴**(첫 화면): 차시별 수업을 위해 **모든 스테이지 열기**, 진행 기록 초기화.
- 진행 기록은 그 기기의 브라우저(localStorage)에만 저장되며, 어떤 정보도 외부로 전송하지 않습니다.

## 파일 구조

```
index.html      화면 뼈대
css/style.css   디자인
js/data.js      학습 데이터 (생물, 먹이그물, 오염 사례, 보전 노력, 스테이지)
js/game.js      게임 진행 로직
```

문제나 생물을 바꾸고 싶으면 `js/data.js`와 `js/game.js` 아래쪽의 `STAGE_SCRIPTS`를 고치면 됩니다.
